## Backend dependency (IMPORTANT)

Moving this folder did NOT move the backend. The app still talks to the Lexlab Next.js app in `C:\Users\PC\Desktop\Codes\LawTest`:

- Production API: `https://lawtest-rho.vercel.app`
- Local dev API: the LawTest server on port 3000 (or 3010 for the revenue dashboard)
- Endpoints used: `/api/mobile/login`, `/api/questions?full=1`, `/api/profile`, `/api/attempts`, `/api/mistakes`, `/api/saved-exams`, `/api/study/todos`, `/api/announcements`, `/api/announcements/read`, `/api/payment-requests`
- Server-side auth/CORS stays in LawTest: `src/lib/mobileAuth.ts`, `src/app/api/mobile/login`, `requestUserId(req)` in the API routes, and the `/api/*` CORS headers in `next.config.ts`
- Some of those server pieces are still local-only in the LawTest working tree. Deploy them before shipping a mobile release.

`src/lib/api.ts` auto-targets the Metro host on port 3000 only in `__DEV__`; production builds fall back to the production URL. Override with `EXPO_PUBLIC_API_URL` when needed. `src/lib/bank.tsx` also has a hardcoded production recovery URL.

## Commands (PowerShell 5.1: run npm/npx through `cmd /c`)

- Install (only if `node_modules` is missing): `cmd /c "npm install"`
- Typecheck: `cmd /c "npx tsc --noEmit"`
- Start Metro: `cmd /c "npx expo start"`
- Android / iOS / web: `cmd /c "npm run android"` / `cmd /c "npm run ios"` / `cmd /c "npm run web"`
- Android export check: `cmd /c "npx expo export --platform android"`
- Backend first (from LawTest): `cmd /c "npm run start -- -H 0.0.0.0 -p 3000"` (or `cmd /c "npm run dev"`)

`npx expo lint` is still unconfigured (ESLint 9 ignores `src` because there is no flat config).

## Stack / layout

- Expo SDK 58.0.17, React Native 0.88, React 19.3, expo-router 58, TypeScript 6
- `src/app/` — Expo Router screens (`(tabs)`, `browse`, `drill`, `plan`, `quiz`, `result`, `login`, `upgrade`, ...)
- `src/components/` — shared UI (`Aurora`, `TabBar`, `NotificationBell`, `PlanBoard`, sheets, ...)
- `src/lib/` — auth, bank, progress, plan, saved exams, quiz launch, theme, types
- Assets live in `assets/`; app config in `app.json`
